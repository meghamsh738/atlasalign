# AtlasAlign Lite

Made by Meghamsh Teja Konda.

AtlasAlign Lite provides reviewer-controlled Allen Mouse Brain CCFv3 alignment,
resumable section batches and source-coordinate ROI exports in Fiji/ImageJ2.
A numbered whole-slide overview links section markers to the review queue.
Source pixels and calibration remain unchanged; users must verify anatomy before
accepting and exporting an alignment.

Requires Java 17+. Manual review needs no Python. Allen atlas data is obtained
separately through the plugin's checksum-verifying setup dialog after terms
acknowledgement. Optional DeepSlice is documented separately.

Project code: MIT. Source, installation, limitations and citation:
[AtlasAlign Lite](https://github.com/meghamsh738/atlasalign).

**Plugins → AtlasAlign Lite → Atlas Setup** followed by **Review Atlas Alignment**
or **Batch / Whole-Slide Review**. See the repository quick start for a synthetic
navigation demonstration and scientific limitations.
